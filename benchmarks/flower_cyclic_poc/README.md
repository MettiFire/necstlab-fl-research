# Flower Cyclic PoC

Questa cartella contiene la versione "proof of concept" (PoC) del benchmark Flower Cyclic, con server e client separati per simulare una federazione reale.

- Copia dei file originali da `flower_cyclic`, modificati per supportare l'avvio separato di server e client.
- Utilizzare questa versione per esperimenti in cui è richiesta la separazione dei processi.
