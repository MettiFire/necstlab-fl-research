# NVIDIA FLARE PoC

Questa cartella contiene la versione "proof of concept" (PoC) del benchmark NVIDIA FLARE, con server e client separati per simulare una federazione reale.

- Copia dei file originali da `nvidia_flare`, modificati per supportare l'avvio separato di server e client (modalità PoC).
- Utilizzare questa versione per esperimenti in cui è richiesta la separazione dei processi.
